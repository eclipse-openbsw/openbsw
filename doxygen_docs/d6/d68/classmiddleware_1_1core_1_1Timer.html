Detailed Description

template<typename T>
class middleware::core::Timer< T >

This Timer class can be used to countdown timespans or ticks.

The Timer is "time" agnostic, which means it can be used for counting down different timespans (ms, seconds, ...) or just ticks. The functionality is determined by the initialisation value and the use of the Timer::decrement() method. To countdown tick, just call the Timer::decrement() method when needed. To countdown times, set the initial value accordingly to the planned frequency and call Timer::decrement() at a regular frequency.

The Timer has three states:

  • Running: The initially set timespan is not expired.
  • Expired: The initially set timespan has expired (
    See also
    Timer::isExpired() ).
  • Reset: The timer is in reset state (
    See also
    Timer::isReset() ). It can be put into the running state by (re)setting to a new, to be counted down, timespan/ticks via Timer::setCounter().
    For compatibility, the maximum value of T maps to the reset state and never expires when decremented. Finite countdowns range from zero (already expired) to the maximum value of T minus one.
