Detailed Description

Cpp2CAN MaskFilter

A filter that matches ids by a bit mask/pattern pair: an id matches if (id & mask) == pattern, i.e. it allows to fix an arbitrary subset of the 32 id bits to a given value while leaving the remaining bits unconstrained ("don't care").

This is useful for addressing schemes that encode information directly into fixed bit positions of the CAN identifier (as opposed to a contiguous range of ids), e.g. ISO 15765-2 normal fixed addressing, where the upper bits of the (29 bit) identifier are fixed while the target/source address bits are not.
