Detailed Description

template<class DataLinkLayer>
struct docan::DoCanExtendedAddressingFilterAddressEntry< DataLinkLayer >

Simple entry type for map entries of an extended addressing filter, mapping a raw (base, 11 bit) CAN identifier to the transport address of the node that transmits on it.

Since with extended addressing the address extension byte carried in a frame's payload always identifies the target of that specific frame, a flat table of these entries is enough to resolve both directions of any connection between the participating nodes: the byte itself gives the target, and looking up its CAN identifier in the table gives the corresponding source (and vice versa for the opposite direction).
