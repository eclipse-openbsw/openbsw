Detailed Description

Size-erased access to a PDU in shared memory.

It keeps the PDU broker code from being instantiated per PDU size. The PDU table generated from the deployment is sorted by ascending PDU ID. PDU IDs are defined in the deployment, are unique and need not be sequential.

Plain function pointers are used so that the table is constant and does not hold shared-memory addresses, which differ between processes.
