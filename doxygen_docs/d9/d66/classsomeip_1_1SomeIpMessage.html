Detailed Description

Class representing a SOME/IP Message and providing methods for its serialization.

SomeIp Header

  • 32 bit: Message ID (Service ID / Method ID)
  • 32 bit: Length
  • 32 bit: Request ID (Client ID / Session ID)
  • 8 bit: Protocol Version
  • 8 bit: Interface Version
  • 8 bit: Message Type
  • 8 bit: Return Code
