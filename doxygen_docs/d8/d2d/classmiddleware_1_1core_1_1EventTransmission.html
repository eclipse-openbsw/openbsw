Detailed Description

template<uint16_t DebounceTimeMs, uint16_t RepetitionIntervalMs, uint8_t Repetitions = 2U>
class middleware::core::EventTransmission< DebounceTimeMs, RepetitionIntervalMs, Repetitions >

This class implements event-triggered transmission with optional repetitions.

Does not own or transmit the PDU; it signals whether a send can happen upon request.

The number of repetitions and the repetition interval must either both be zero or both be greater than zero (enforced via static_assert).

Template Parameters
DebounceTimeMsThe debounce time in milliseconds.
RepetitionIntervalMsThe interval between repetitions in milliseconds. Required.
RepetitionsThe number of repetitions after the initial event trigger. Default is 2.

Called every cycle by the owning TransmissionMode to tick the debounce and repetition timers.

Releases a pending event after debounce expires and starts its repetition sequence. Multiple pending events coalesce. Repetitions do not restart debounce.

true if a transmission should happen, false otherwise.
