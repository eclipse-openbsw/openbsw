virtual void someip::IServiceListener::updateEventgroupDescription ( ServiceDescription &  ,
ServiceStatus   
)
pure virtual

Pure virtual function to give an IServiceListener the possibility to update the ServiceDescription of an event group query. This is important in case of TCP client connections where the local port needs to be updated. This update function will be called after the serviceStatusChanged() function so that the IServiceListener has the chance to compute a new local port and open the TCP connection. The updated event group ServiceDescription will be reflected in the following subscribe packets.

Parameters
eventGroupServiceDescription of the event group.
statusIndicates if the parent service became available or unavailable.
