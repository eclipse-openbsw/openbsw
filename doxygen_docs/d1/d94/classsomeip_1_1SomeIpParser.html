Detailed Description

The SomeIpParser class provides an easy way to parse Some/IP types from raw bytes. The class is created with a buffer to ensure that buffer overwrites do not happen. If a parser object enters an error state all subsequent reads will be empty operations; they will not cause other problems.

Usage example

void parser(::etl::span<const uint8_t> source, ISomeIpSerializable& obj)
{
SomeIpParser parser(source);
// read the object
parser >> obj;
// read some more data
uint32_t value;
parser >> value;
}
