Detailed Description

template<class MessageSize = uint16_t, class FrameSize = uint8_t, class FrameIndex = uint16_t>
class docan::DoCanNormalFixedAddressing< MessageSize, FrameSize, FrameIndex >

helper class for encoding/decoding frame payloads with ISO 15765-2 normal fixed addressing.

With normal fixed addressing, the network address information is fully contained in the (29 bit, extended) CAN identifier:

bit 28-16: fixed to 0x18DA (physical) or 0x18DB (functional), see ISO 15765-2
bit 15-8: target address (physical) or functional address (functional)
bit 7-0: source address

This class packs/unpacks these fields into/from a single (already fully qualified, i.e. carrying the extended id qualifier bit of can::CanId) CAN identifier, so it can be used with the rest of the docan address handling infrastructure (see DoCanNormalAddressing/ DoCanExtendedAddressing for comparison).
