Detailed Description

template<typename IdQueue, size_t MaxPduSize>
class middleware::core::PduBrokerConnection< IdQueue, MaxPduSize >

Connects the bus to the PDUs in shared memory.

PDUs received from the bus are stored in shared memory by onReceive(). Writers queue the ID of each PDU they commit; this class drains the queue, so no search over shared memory for pending PDUs is needed.

Template Parameters
IdQueuemiddleware::queue::Queue of uint32_t, filled by the PDU writers.
MaxPduSizesize in bytes of the largest PDU. Use the generated middleware::shm::PduBrokerConnection alias, which sets it.
Note
Thread safety: single consumer of the queue. onReceive() and processTransmissions() must be called from the same context.

template<typename IdQueue , size_t MaxPduSize>
void middleware::core::PduBrokerConnection< IdQueue, MaxPduSize >::processTransmissions ( )
inline

Hands the committed PDUs over to the sink in commit order.

Every ID is removed from the queue as soon as the PDU is handed over, so a sink that is busy or failing never blocks the PDUs behind it. The sink owns pending transmissions, retries and drops. IDs that are not PDU IDs are discarded.
