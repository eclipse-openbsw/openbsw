20 // IWDG driver for STM32; the board safety manager services it cyclically.
21 //
22 // STM32 IWDG specifics:
23 // - LSI clock ~32 kHz (not trimmed - 17..47 kHz depending on device)
24 // - 12-bit reload register (0..4095)
25 // - Once started, cannot be disabled (hardware limitation)
26 // - Kick sequence: write 0xAAAA to KR
27 // - Unlock sequence: write 0x5555 to KR, then configure PR + RLR
28 // - Start sequence: write 0xCCCC to KR
