Detailed Description

A ManagedOutgoingDiagConnection is used by OutgoingDiagConnectionManager.

This class exposes management functions that allow the OutgoingDiagConnectionManager to set parameters of the connection that are read-only for a AbstractDiagApplication which is the reason why the reduced interface of OutgoingDiagConnection is used there.
