Detailed Description

template<typename... TStrategies>
class middleware::core::TransmissionMode< TStrategies >

TransmissionMode combines multiple strategies. On execution, it executes every strategy in order and aggregates their send requests. On event trigger, it triggers all strategies that have a trigger() method.

Template Parameters
TStrategiesThe strategies to combine. Every strategy must have an execute() method. Strategies with a trigger() method will have it triggered on event trigger.
