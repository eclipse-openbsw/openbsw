Detailed Description

template<typename MethodTraits, uint8_t REQUEST_LIMIT = 1U>
class middleware::rpc::ProxyMethod< MethodTraits, REQUEST_LIMIT >

Proxy-side representation of a remote method, managing a pool of futures with callbacks for asynchronous request/response communication.

Template Parameters
MethodTraitsCompile-time traits (InputType, OutputType, TIMEOUT)
REQUEST_LIMITMaximum number of concurrent in-flight requests
