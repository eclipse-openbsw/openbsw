Detailed Description

template<typename TMode1, typename TMode2 = TransmissionMode<NoTransmission>>
class middleware::core::TransmissionModeManager< TMode1, TMode2 >

Combines two TransmissionMode instances and switches between them at runtime based on a boolean condition.

Does not own or transmit the PDU itself; instead it returns whether the PDU should be sent, leaving the actual transmission to the PDU owner.

  • Holds two transmission modes and delegates to the currently active one.
  • Switches the active mode via setActiveCondition(): when the condition is true the second mode is active, otherwise the first.
Template Parameters
TMode1The first transmission mode.
TMode2The second transmission mode (defaults to TransmissionMode<NoTransmission>).
