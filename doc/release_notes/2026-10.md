# Release Notes

## [2026-10]

### Added

* Bazel build support across platforms, `libs/bsp`, `libs/bsw`, `libs/safety`, FreeRTOS,
  ThreadX, lwIP, referenceApp and unit tests, incl. an `arm_none_eabi` GCC toolchain
* Middleware: signal/RPC framework with proxy, skeleton, cluster connections,
  shared-memory simulation for POSIX and a jinja2cpp code generator
* SOME/IP implementation module `cpp2someip`
* DoIP server (ISO 13400) for UDS over Ethernet
* DoCAN extended and normal fixed addressing (ISO 15765-2), incl. pytest coverage
* UDS services `ReadDTCInformation` (0x19) and `ClearDiagnosticInformation` (0x14),
  configurable diagnostic sessions and outgoing diagnostic connections
* STM32 platform support: MCU foundation, BSP drivers, bxCAN/FDCAN transceivers,
  ThreadX and FreeRTOS board configs (G474RE, F413ZH, Nucleo)
* Rust support: build integration, `openbsw_async` (Embassy) bridge, `console_out`,
  `openbsw_panic_handler`, logging bridge and vendored crates for offline builds
* Persistent storage module, EEPROM drivers for POSIX and S32K1, and a new UART interface
* Ethernet/UDP multicast support, CAN-FD for POSIX, tracing feature and safety modules
* Copyright checker tooling (`cr_checker`), pre-commit/gitlint config and clang-tidy CI
* `routing` and `blob` modules, `shed` library and `TimestampProvider`

### Changed

* Minimum required C++ standard raised to C++17
* Migrated from `estd` to ETL throughout the codebase (containers, slices, endianness,
  CRC, queues, asserts, formatting); updated ETL to 20.49.0
* Replaced `platform` library abstractions (`estdint.h`, `config.h`, `ESR_*` macros)
  with standard headers and ETL equivalents
* Build system restructured: multiple executables, CMake presets, separate unit-test
  binaries, Docker images updated to Ubuntu 24.04 and GCC ARM 14.3.rel1
* Diagnostics refactored: `DiagDispatcher` consolidation, connection handling simplified
* `PLATFORM_SUPPORT_IPV6` replaces `OPENBSW_NO_IPV6` and defaults to off
* Documentation restructured, generated with Doxygen and extended for middleware,
  DoCAN, blob/routing and the STM32 boards

### Fixed

* Data races and undefined behaviour in `QueueBase`, `PoolBase` and generated
  middleware code (atomics, strict aliasing, static init order)
* S32K148 startup: ECC initialization, vector table relocation, linker script
  compatibility with `ld.lld` and clang runtime errors
* ENET ISR race during Ethernet driver init and TJA1101 MDIO/RMII configuration
* POSIX defects: stdin read error handling, EEPROM driver file handles,
  TAP interface restart and lwIP netif persistence across lifecycle transitions
* Numerous clang-tidy, compiler-warning and flaky pytest issues

### Removed

* Support for C++14
* `estd` containers and the `platform` library, incl. `platform/config.h`
* `spsc/Queue.h` and `spsc/ReadWrite.h` in favour of ETL equivalents
* Unused code: `StderrLogger`, `DiagConnectionManager`, `IDataProgressListener`,
  `AbstractDiagnosisConfiguration`, variant handling and many trivial getters/setters
